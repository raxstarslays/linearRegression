# linearRegression
💼 Salary Prediction using Simple Linear Regression

This project demonstrates a Simple Linear Regression machine learning model to predict salary based on years of experience using Python and scikit-learn.
The dataset is sourced from Kaggle, and the project was developed using Google Colab.

📌 Project Overview

Algorithm Used: Simple Linear Regression

Input Feature: Years of Experience

Target Variable: Salary

Language: Python

ML Library: scikit-learn

The model is trained on historical salary data and evaluated using standard regression metrics.

📂 Dataset

Source: Kaggle

Dataset Name: Salary Dataset – Simple Linear Regression

Link: https://www.kaggle.com/datasets/abhishek14398/salary-dataset-simple-linear-regression

⚙️ Installation & Setup

Clone the repository

git clone https://github.com/your-username/salary-prediction-linear-regression.git
cd salary-prediction-linear-regression


Install required libraries

pip install pandas numpy matplotlib scikit-learn kaggle


Set up Kaggle API

Create a Kaggle account

Generate an API key from Account Settings

Set environment variables:

export KAGGLE_USERNAME=your_username
export KAGGLE_KEY=your_api_key


⚠️ Important: Never upload your Kaggle API key to GitHub.
